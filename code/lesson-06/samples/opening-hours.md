# Opening hours

Maple Grove Community Library is open:

- Monday to Friday: 9:00 to 19:00
- Saturday: 10:00 to 16:00
- Sunday: closed

On public holidays the library is closed. During the summer break (July and August)
we close at 17:00 on weekdays.

The book return box next to the main entrance is open 24 hours a day.
Items returned on a Sunday are checked in on Monday morning.
